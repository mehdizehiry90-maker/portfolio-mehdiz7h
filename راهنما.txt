اجرای سایت روی سیستم خودت
==========================

۱) پایتون ۳ را نصب کن
   ویندوز: https://www.python.org/downloads/
   موقع نصب تیک "Add python.exe to PATH" را بزن.
   مک: معمولاً از قبل هست. اگر نبود از python.org

۲) کل پوشهٔ portfolio را روی کامپیوترت کپی کن
   (همین پوشه که index.html و server.py داخلش است)

۳) ترمینال / CMD را باز کن و برو داخل همان پوشه:

   cd مسیر\پوشه\portfolio

۴) کتابخانه را نصب کن:

   python -m pip install -r requirements.txt

   اگر python کار نکرد بنویس:  py -m pip install -r requirements.txt

۵) سایت را روشن کن:

   python server.py

   یا:  py server.py

۶) مرورگر را باز کن:

   سایت:     http://127.0.0.1:3000
   پنل ادمین: http://127.0.0.1:3000/admin

   کاربر: mehdiz7h
   رمز:   studio2026

   بعد از ورود از تب «رمز» عوضش کن.

توقف: داخل ترمینال Ctrl+C

نکته‌ها
- اینترنت فقط برای فونت انگلیسی گوگل لازم است. استعداد از پوشهٔ fonts خوانده می‌شود.
- عکس‌هایی که از پنل آپلود کنی می‌روند داخل images/uploads
- متن و کارها در data/site.json ذخیره می‌شوند.
- این سرور برای تست روی سیستم خودت است، نه برای اینترنت عمومی.
